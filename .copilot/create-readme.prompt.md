# GitHub Copilot Prompt

This prompt are designed to help GitHub Copilot automatically generate README content by analyzing the project structure, code, dependencies, and features of the repository:

```markdown
## Instructions for GitHub Copilot:

- Analyze the directory structure and files in this repository.
- Generate a comprehensive README file that includes:
  - Project title and description
  - Installation instructions
  - Usage examples
  - List of features
  - Information about contributing
  - License information

---

## Project Structure:
- Describe the purpose of each major component.

## Dependencies:
- List the main dependencies used in the project.

## Features:
- Highlight the key features of the project.
```
